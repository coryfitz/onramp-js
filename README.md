# onramp-js

`onramp-js` creates a web-first universal React Native app that can grow into
iOS and Android when those platforms are needed. It also powers the frontend
generated by the OnRamp Python app framework.

## Create an app

```sh
npx onramp-js create myapp
cd myapp
npm run start:web
```

By default, `create` writes the shared application, installs its npm
dependencies, and generates its initial file-based route registry without
spending time creating native platform projects.

Include mobile projects during creation when desired:

```sh
npx onramp-js create myapp --mobile
npx onramp-js create myapp --all
```

`--mobile` and `--all` currently include both iOS and Android. The separate
`--all` option leaves room for more OnRamp targets in the future.

## Add native platforms later

From an app created by `onramp-js`:

```sh
npx onramp-js add ios
npx onramp-js add android
npx onramp-js add mobile
```

The `add` command is safe to run again; platform directories that already
exist are left in place.

## Check and run platforms

`doctor` checks the required development tools without changing the app:

```sh
npx onramp-js doctor web
npx onramp-js doctor ios
npx onramp-js doctor android
npx onramp-js doctor all
```

Run the app directly through `onramp-js`:

```sh
npx onramp-js run web
npx onramp-js run ios
npx onramp-js run android
```

The native run commands add a missing platform automatically. The iOS command
checks Xcode and CocoaPods, installs Pods, selects a compatible simulator, and
offers to download a missing simulator runtime. The Android command locates
the SDK, selects JDK 17 and an installed virtual device, then wakes and unlocks
the emulator after launching the app.

If an iOS dependency installation needs to be rebuilt:

```sh
npx onramp-js repair ios
```

## OnRamp Python integration

The Python framework uses the explicit form so its generated frontend remains
in the app's `build` directory:

```sh
npx onramp-js create --name myapp --output /path/to/myapp/build
```

Running `onramp ios` or `onramp android` delegates the complete frontend
preparation and launch to these same `onramp-js` commands. Python remains
responsible for its backend and for coordinating the frontend process with it.
